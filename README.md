 Product-Price-Reporter

This project implements a data analysis and reporting system for global commodity prices, using historical data from 1960 to 2023. The system follows a two-tier architecture (front-end / back-end) and is designed to support structured data processing and analytical queries.

The back-end is responsible for loading data and metadata from external files (via a configuration .ini file), managing in-memory representations, and providing analytical services through a well-defined API. Supported functionalities include price reports per year, product, and time range, identification of top-trending products and categories based on news relevance, and computation of basic statistics such as minimum, average, maximum, and latest prices.
